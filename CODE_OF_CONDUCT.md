# Code of Conduct

## Our standard

hoardCTI adopts the **[Contributor Covenant, version 2.1][covenant]** as the
code of conduct for every repository, issue tracker, discussion, and
communication channel in this organisation.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Please read the canonical text at the link above. It is authoritative; this
file adds only the enforcement details specific to us. In summary, we expect
participants to show empathy and respect, accept constructive feedback
gracefully, and prioritise what is best for the wider community — and we do not
tolerate harassment, personal attacks, publishing others' private information,
or other conduct reasonably considered inappropriate in a professional setting.

## Scope

This applies in all project spaces and whenever an individual is officially
representing the project in public.

## Reporting

Report abusive, harassing, or otherwise unacceptable behaviour to the project
maintainers at **<!-- TEMPLATE: conduct contact -->
support@hoardcti.com**.

All complaints will be reviewed and investigated promptly and fairly. We
respect the privacy and security of the reporter of any incident.

Do not use this address for security vulnerabilities — those go through
[SECURITY.md](SECURITY.md).

## Enforcement

Maintainers follow the Contributor Covenant's
[Enforcement Guidelines][guidelines] when determining consequences, which
escalate from a private correction, through a warning and a temporary ban, to
a permanent ban.

[guidelines]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines

Maintainers who do not follow or enforce this code in good faith may face
temporary or permanent repercussions as determined by other members of the
project's leadership.
